# Saba Art (صبا آرٹ) — Original Handmade Paintings & Islamic Calligraphy

Bespoke handmade paintings, timeless Quranic calligraphy, fine landscapes, and spiritual art thoughtfully created by **Saba Art** to bring beauty, tranquility, and inspiration into your space.

## ✨ Features
- **100% Original Hand-Painted Masterpieces**: 14 curated original paintings (Islamic Calligraphy, Landscapes, Seascapes, Sufi Whirling Dervish Art, Modern Art).
- **Background-Free Studio Photography**: All high-resolution artworks cropped and rotated to showcase pure canvas texture without background distractions.
- **Interactive Virtual Wall Visualizer ("View on Wall")**: Visualize any artwork hanging in real-time against customizable wall colors (Modern Charcoal, Warm Alabaster, Regal Navy, Serene Sage, Terracotta) and floating frame styles (Gold, Onyx, Frameless).
- **Deep Zoom Modal**: Explore fine brushstrokes, impasto textures, and Arabic Thuluth calligraphy up close.
- **Bespoke Custom Commission Studio**: Request custom Quranic Surahs, personalized name calligraphy, custom dimensions, and color schemes directly via WhatsApp.
- **Seamless WhatsApp Shopping & Order Flow**: One-click inquiry and order buttons with pre-filled receipts and celebratory confetti.
- **Built with Modern Tech**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons, and Canvas Confetti.

## 🚀 Running Locally
```bash
npm install
npm run dev
```

## 📦 Building for Production / Vercel
```bash
npm run build
```
Deploy to Vercel simply by importing the repository: `https://github.com/nomanthebestnoman/Saba-Art`.
Framework preset: **Vite**
Build command: `npm run build`
Output directory: `dist`
